# Artwork and fonts

## Usagi PNG artwork

Original artwork downloaded from the official Chiikawa anime website on 2026-11-14.

- Site and visual reference: https://www.anime-chiikawa.jp/
- `usagi-standing.png`: https://www.anime-chiikawa.jp/images/bg_top_usagi_01.png
- `usagi-footer.png`: https://www.anime-chiikawa.jp/images/bg_foot_usagi.png
- `usagi-running.png`: https://www.anime-chiikawa.jp/images/bg_top_usagi_dash.png (original motion accent; currently unused)

Additional original assets:

- `usagi-loading.png`: https://www.anime-chiikawa.jp/images/loading/usagi.png
- `usagi-shout.png`: https://www.anime-chiikawa.jp/images/loading/usagi_shout1.png (currently unused)
- `usagi-shout-alt.png`: https://www.anime-chiikawa.jp/images/loading/usagi_shout2.png (currently unused)
- `usagi-character.png`: https://www.anime-chiikawa.jp/images/img_chara_03.png (currently unused)

The footer PNG is an original two-frame sprite. CSS displays its first frame at its original 317:415 aspect ratio without modifying the image.
Artwork credit: © nagano / chiikawa committee. These source links document provenance and do not constitute a redistribution license.

## Fonts

- Pretendard Variable 1.3.9: https://github.com/orioncactus/pretendard — SIL Open Font License; license bundled in `fonts/Pretendard-LICENSE.txt`.
- Gowun Dodum: https://github.com/google/fonts/tree/main/ofl/gowundodum — SIL Open Font License; license bundled in `fonts/GowunDodum-OFL.txt`.
- Jua (current display font): https://github.com/google/fonts/tree/main/ofl/jua — SIL Open Font License; license bundled in `fonts/Jua-OFL.txt`.

The fonts are bundled locally and require no network access at runtime. The current interface uses Jua for display text and Pretendard for body text; Gowun Dodum is retained as an unused asset.
