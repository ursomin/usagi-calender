# 우사기의 하루 — 0.1 디자인 프로토타입

밝은 노란색과 파스텔 문구류 테마의 Windows용 달력 앱입니다. HTML/CSS/JavaScript로 만든 화면을 Electron으로 데스크톱 앱으로 실행합니다. 공식 사이트에서 가져온 우사기 PNG와 로컬 글꼴(Pretendard·주아)을 사용합니다.

## 현재 구현된 기능

- 월 단위 달력 이동, 날짜 클릭 시 해당 날짜 일정 표시
- **날짜 더블클릭 → 일반 일정 등록**
- **오른쪽 위 '반복 일정 추가' → 반복 일정 등록**
- 교회 / 회사 / 개인일정 카테고리 지정, 필터링
- 일정 추가/수정/삭제, 하루 종일 또는 시작/종료 시각 지정
- 매일·매주·매월·매년 및 N일/N주/N개월/N년 간격 반복, 종료일 선택
- 메모 자동 저장
- 내 컴퓨터에만 저장 (별도 계정·인터넷·서버 불필요)

**현재 한계**: 반복되는 일정은 기본적으로 전체 시리즈를 수정/삭제합니다. 특정 회차만 예외 처리하는 기능, 알림, 클라우드 동기화, 커스텀 카테고리 생성은 아직 없습니다. 월말 31일과 같이 해당 날짜가 없는 달에는 월간 반복 일정이 건너뛰어집니다. 이것은 첫 번째 시제품입니다.

## 0. 코드 설치 없이 디자인 미리보기

`preview.html`을 Chrome/Edge에서 열면 이미지가 아닌 실제 HTML/CSS/JavaScript 인터페이스를 볼 수 있습니다.

- 이 파일은 **체험용 예시 일정이 들어간 디자인 데모**입니다.
- 새로고침하면 데모에서 변경한 일정은 초기화됩니다.
- 실사용 및 데이터 저장을 위해 아래 Electron 앱을 실행하세요.
- 원본 화면을 수정한 뒤 `npm run preview:build`로 미리보기를 다시 생성합니다. PNG와 글꼴까지 포함한 단일 HTML입니다.

## 1. Windows에서 개발 중 실행하기

1. Node.js LTS를 설치합니다: https://nodejs.org/
2. 압축을 푼 폴더의 터미널(명령 프롬프트 또는 PowerShell)을 엽니다.
3. 순서대로 실행합니다.

```powershell
npm install
npm start
```

`npm install`은 처음 한 번만 실행하면 됩니다. `npm start`로 앱을 실행한 후에는 인터넷 없이 사용할 수 있습니다.

## 2. 친구에게 보낼 .exe 만들기

Windows PowerShell에서:

```powershell
npm run build:win
```

완료되면 `dist/` 폴더에 설치형 `.exe`와 설치 없이 실행 가능한 포터블 `.exe`가 만들어집니다. 친구는 **빌드된 실행 파일만** 받으면 되며 Node.js를 설치할 필요가 없습니다.

**주의:** 이 압축 파일에는 node_modules와 설치형 `.exe`를 넣지 않았습니다. Windows에서 위 명령으로 빌드해야 합니다. 개인 개발자가 코드 서명 없이 배포하면 Windows SmartScreen에서 확인 경고가 나올 수 있으므로, 친구에게 출처와 배포 내용을 명확히 알리고 본인이 만든 파일만 배포하세요.

## 3. 파일 구성

```
bunny-calendar/
├─ main.js            Electron 메인 창 실행, 창 버튼 처리
├─ preload.js         화면에 최소한의 창 제어 API만 노출
├─ package.json       실행 및 Windows 설치 파일 빌드 설정
├─ preview.html       인터넷 없이 열어보는 디자인 시연용 HTML
└─ src/
   ├─ index.html      캘린더 화면 구조
   ├─ styles.css      노란색 테마 및 레이아웃
   ├─ app.js          일정·반복·메모 기능
   └─ assets/         우사기 PNG, 로컬 글꼴 및 출처 정보
```

## 4. 캐릭터 저작권

현재 화면은 [먼작귀 애니메이션 공식 사이트](https://www.anime-chiikawa.jp/)의 실제 우사기 PNG를 사용합니다. 이미지별 원본 주소와 글꼴 라이선스는 `src/assets/SOURCES.md`에 기록했습니다. 이미지의 공개 주소는 재배포 허가를 의미하지 않으며, 외부 배포 전 별도 이용 조건 확인이 필요합니다.

## 5. 저장 방식

일정과 메모, 카테고리 필터는 Electron 앱이 실행되는 사용자 컴퓨터의 `localStorage`에 자동 저장됩니다. 다른 컴퓨터와 공유되지 않습니다. 백업·불러오기 기능은 제공하지 않습니다.
